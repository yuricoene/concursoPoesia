# Concurso de Poesia: Meias Perdidas 🧦

O **Concurso de Poesia: Meias Perdidas** é um site interativo desenvolvido para apresentar uma iniciativa poética inspirada nos pequenos mistérios do cotidiano — como o sumiço de meias na lavanderia. O projeto conta com um carrossel dinâmico em destaque, navegação por botões/indicadores e cards estilizados com foco em autores renomados da literatura brasileira e informações do evento.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização moderna, animações (`keyframes`), layouts flexíveis (`Flexbox`) e paleta de cores personalizada.
* **JavaScript (ES6+):** Lógica do carrossel interativo, alternância de classes e controle dos botões e indicadores.
* **Google Fonts:** Tipografias *Montserrat Alternates* e *Orbitron*.
* **SVG:** Vetores escaláveis para ilustrações e ícones sem perda de qualidade.

---

## 📋 Dependências e Versões Necessárias

Não é necessária a instalação de dependências externas ou servidores complexos.

* **Navegador Web:** Google Chrome, Firefox, Edge ou Safari em versão recente.
* **Editor de Código (Opcional):** VS Code com a extensão *Live Server* recomendada.
